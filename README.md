# Zgadnij Miesiąc
Czy jesteś w stanie zgadnąć miesiąc po zdjęciu? Zgadnij Miesiąc to prosta gra oparta na spostrzegawczości i zgadywaniu. Wszystkie zdjęcia zostały wykonane w Polsce, dlatego też ta gra jest skierowana dla ludzi żyjących w Polsce, no bo każdy miesiąc może wyglądać nieco inaczej w zależności o położenia geograficznego.
